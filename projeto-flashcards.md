# Projeto Flashcards Educativos

## Descrição

O projeto Flashcards Educativos foi desenvolvido com o objetivo de facilitar a aprendizagem por meio de cartões interativos. Os flashcards permitem que o aluno visualize uma pergunta ou conceito na frente do cartão e sua resposta no verso, tornando o estudo mais dinâmico e eficiente.

Essa metodologia auxilia na memorização, revisão de conteúdos e fixação de conceitos importantes de forma prática e organizada.

---

# Objetivo

Criar um site de estudos utilizando flashcards interativos para ajudar estudantes a revisar conteúdos de tecnologia e programação.

---

# Flashcards Desenvolvidos

## Flashcard 1

### Frente
**O que é HTML?**

### Verso
HTML (HyperText Markup Language) é a linguagem utilizada para estruturar o conteúdo das páginas da web.

### Imagem
Logo HTML.

---

## Flashcard 2

### Frente
**O que é CSS?**

### Verso
CSS (Cascading Style Sheets) é a linguagem responsável pela aparência visual das páginas, definindo cores, fontes, espaçamentos e layouts.

### Imagem
Logo CSS.

---

## Flashcard 3

### Frente
**O que é JavaScript?**

### Verso
JavaScript é a linguagem de programação utilizada para adicionar interatividade e funcionalidades aos sites.

### Imagem
Logo JavaScript.

---

# Benefícios dos Flashcards

- Aprendizagem rápida e prática.
- Melhor fixação do conteúdo.
- Revisão eficiente para provas e exercícios.
- Organização dos conceitos estudados.
- Método interativo e divertido.

---

# Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Figma
- GitHub

---

# Funcionamento

1. O usuário acessa o site.
2. Visualiza os flashcards disponíveis.
3. Clica no cartão para visualizar a resposta.
4. Navega pelos demais conteúdos para reforçar o aprendizado.

---

# Conclusão

O projeto Flashcards Educativos demonstra como a tecnologia pode ser utilizada para facilitar o processo de aprendizagem. Através de cartões interativos, os estudantes conseguem revisar conceitos importantes de forma rápida, organizada e eficiente, tornando os estudos mais produtivos.
